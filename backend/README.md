# Backend - Sistema de Gestión de Confección

Estructura base para el **Incremento 1** del proyecto.

## Pasos para ejecutar:
1. Asegúrate de tener Node.js instalado.
2. Abre una terminal en esta misma carpeta (donde está `package.json`).
3. Ejecuta `npm install` para instalar todas las dependencias.
4. Ejecuta `npm run dev` para iniciar el servidor.
5. Verifica en la consola que aparezca `🚀 Servidor corriendo en el puerto 3000` y `✅ Conexión a MySQL establecida correctamente`.

(Asegúrate de que tu base de datos MySQL local esté encendida con el usuario root y contraseña 12345).
